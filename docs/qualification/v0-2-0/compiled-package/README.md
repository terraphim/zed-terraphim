# Released Zed package qualification

These are actual saved outputs from a fresh stock-Zed 1.23.3 profile on macOS ARM64 using the downloaded Terraphim LSP extension 0.2.0 archive. The installed 319,339-byte WASM exactly matches the original CI release artifact. The extension automatically downloaded the checksum-verified public RC7 server.

The receipt binds the public release, immutable source, CI artifact, installed module, server and each saved output. It distinguishes authored alternatives from word swapping and from the preauthored Trim input. The dirty-JSON case uses an unsaved interior edit while a different graph is waiting to export. Both buffer and disk were preserved, then a subsequent intentional save allowed export.

This is a manual compiled-package installation through Zed's Install Dev Extension action, not an official catalog installation. Functional observations exist in the native tool transcript; no downloadable screenshot or video is claimed. Source-dev qualification remains in the sibling source-qualification.json with its distinct module hash. The Zed application fork is separate.
